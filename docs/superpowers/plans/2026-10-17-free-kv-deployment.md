# Free KV deployment implementation plan

**Goal:** R2 구독을 거절한 사용자의 선택을 유지하면서 Pages와 기존 분석 화면을 무료 Workers KV 저장소로 배포한다.

**Architecture:** 로컬 수집은 기존 R2 에뮬레이터를 유지한다. 운영 조회는 `RENT_SNAPSHOTS` KV의 완료된 집계 객체를 읽고 기존 검증·투영·계산을 재사용한다. KV는 조건부 쓰기를 지원하는 R2 수집 저장소로 가장하지 않으며 운영 수집 API는 비활성화한다. 필요하면 실행 환경에서 확인된 성능 문제만 추가 보완한다.

**Constraints:** R2 구독·유료 플랜을 활성화하지 않는다. API 키는 이미 등록한 Production 암호화 Secret에만 존재하며 출력하지 않는다. 데이터는 비공개 KV에 저장하고 정적 자산·Git에 포함하지 않는다. 사용자 요청의 취지는 직접 실행이며 추가 설계 승인 질문을 하지 않는다.

- [x] `tests/kv.test.mjs`: R2/KV 동일한 조회, 도시·자치구 비교, 손상된 저장 자료 차단, KV에서 수집 쓰기 금지 테스트. KV 미지원으로 503을 반환하는 실패를 먼저 확인했다.
- [x] `src/server/summary.js`에 읽기 전용 KV 폴백을 추가하고 해당 테스트를 통과시켰다.
- [x] Production/Preview 전용 KV namespace 생성. `wrangler.jsonc`의 환경별 R2는 빈 배열, KV 바인딩은 분리했다. 기본 로컬 R2는 유지한다.
- [x] 내보낸 25개 구·50개 객체를 검증 후 KV bulk로 업로드했다. 사용자가 무료 KV 전송을 명시적으로 허용했다. 약 28.6MB·50회 쓰기이므로 무료 저장·쓰기 한도 이내이다.
- [x] 전체 테스트 70개·정적 빌드 29개 자산·키 없는 Functions 컴파일 통과. 독립 검토에서 읽기 전용 동작·기간 검증·운영 바인딩을 확인했다. 식별자 예외의 전역 확장 지적은 실제 JSONC 토큰 위치만 인정하도록 수정하고 RED→GREEN 테스트로 검증했다. 커밋 전 업로드 검사를 적용한다.
- [ ] Pages에 실제 배포하고 공개 API·지도·차트·두 지역 비교를 확인한다. 실서비스 주소와 수동 갱신·무료 한도를 README에 기록한다.

## Review focus

- KV 객체의 임의 필드·손상 JSON·누락 포인터는 원문 노출 없이 차단되어야 한다.
- KV 읽기 폴백이 R2 수집의 ETag 조건부 갱신을 흉내 내서는 안 된다.
- KV 전파 중 기간이 다른 구들은 도시 합계로 합쳐서는 안 된다.
- Pages 운영 바인딩에 미활성 R2가 남으면 안 된다.
- 운영의 CPU/메모리 및 조회 결과는 실제 배포에서 확인한다.
